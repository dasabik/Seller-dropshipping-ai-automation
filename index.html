Seller Help & Safe Launch

Quick guidance for common first steps.

How do I choose a product?

Compare verified supplier quality, delivery times, return terms, competition, product demand, and total landed cost. Order a sample where possible before listing.

How do I avoid losing money?

Include supplier cost, platform/payment fees, shipping, packaging, ad spend, taxes where applicable, refunds, RTO and damaged-item allowance. Use actual fee schedules before making a decision.

How do live operations become available?

Live marketplace order sync, payment, courier booking, marketplace publishing and generative AI require approved provider integrations and verified server-side adapters. Locally entered workspace records are not automatically synced to external services.

What should I never store here?

Do not enter marketplace passwords, API secrets, payment credentials, full customer addresses or other sensitive customer data. Browser storage is not a secure production database.

Security & Integration Readiness

Current status: local prototype only. These controls must be implemented on a server before real customers or stores are connected.

  • Server-side authentication, password hashing (Argon2id/bcrypt), email verification, rate limiting, and secure session cookies.
  • Role-based access, MFA for sensitive actions, audit logs, and session revocation.
  • Encrypt integration tokens at rest; keep API keys and secrets on the backend, never in HTML or browser storage.
  • Validate inputs server-side; use parameterized database queries, output encoding, CSRF protection, and a restrictive Content Security Policy.
  • OAuth state/PKCE, least-privilege scopes, verified webhook signatures, replay protection, and idempotent order/dispatch actions.
  • Backups, monitoring, dependency updates, privacy/retention controls, and explicit confirmation before publishing or dispatching.

This checklist is guidance, not a claim that these production controls are already active.
